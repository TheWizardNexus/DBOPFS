# Security policy

## Supported version

Security fixes are provided for the current `1.x` release line.

## Reporting a vulnerability

Do not publish exploit details, user data, credentials, or sensitive storage contents in a public issue. Use GitHub's private vulnerability-reporting feature for this repository. If that feature is unavailable, open a minimal issue asking the maintainers for a private reporting channel.

Application-ID folders reduce accidental access between apps sharing one origin; they do not stop hostile or compromised same-origin code. Use separate domains, subdomains, or browser profiles when applications require security isolation. See [Application folders and same-origin apps](https://thewizardnexus.github.io/DBOPFS/architecture.html#security) for the full explanation.
