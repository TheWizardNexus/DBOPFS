Intended release model

Noncommercial use

The intended license permits qualifying noncommercial use subject to its definitions, conditions, attribution requirements, restrictions, and termination terms.

“Noncommercial” is determined by the actual governing license—not by an informal assumption that a project is small, free to download, educational, charitable, internal, or not yet profitable.

Separate agreement

Commercial use

Organizations and individuals who want to use DBOPFS commercially must request a separate written commercial license and pay the fee agreed with The Wizard Nexus. No commercial permission is implied by an npm download, repository access, playground use, or this documentation.

Request a commercial license

Describe the product, organization, distribution model, expected users, and how DBOPFS will be used. The Wizard Nexus can then confirm whether a commercial license is required and provide the applicable nominal fee and terms.
