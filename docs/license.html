Intended release model

Noncommercial use

The intended license permits qualifying noncommercial use subject to its definitions, conditions, notice requirements, restrictions, and termination terms.

“Noncommercial” is determined by the actual governing license—not by an informal assumption that a project is small, free to download, educational, charitable, internal, or not yet profitable.

Redistribution requirement

Preserve the required notices.

PolyForm's Notices clause requires anyone distributing any part of DBOPFS to provide the license terms or official URL and every plain-text line supplied by the licensor that begins with Required Notice:.

Required Notice lines—copy exactly
Required Notice: Copyright 2026 The Wizard Nexus.
Required Notice: Commercial use is not granted by the public license. See COMMERCIAL-LICENSE.md.

Download the deployed NOTICE.txt, LICENSE.txt, and COMMERCIAL-LICENSE.md. Both the npm package and GitHub Release tarball already include the governing license and these required notice lines.

No source header is missing. PolyForm Noncommercial 1.0.0 has no standard source-file license header. The preserved runtime files do not need implementation edits to satisfy that requirement.

Separate agreement

Commercial use

Organizations and individuals who want to use DBOPFS commercially must request a separate written commercial license and pay the fee agreed with The Wizard Nexus. No commercial permission is implied by an npm or GitHub Release download, repository access, playground use, or this documentation.

Request a commercial license

Describe the product, organization, distribution model, expected users, and how DBOPFS will be used. The Wizard Nexus can then confirm whether a commercial license is required and provide the applicable nominal fee and terms.

Third-party notices

The release may include or bundle third-party software with its own license. Those terms remain applicable to that third-party material and do not expand the DBOPFS license.

Review the deployed third-party notices, package contents, dependency licenses, and final 1.0.0 release evidence before redistribution.
