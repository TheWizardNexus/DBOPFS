What 1.0.0 must prove

Compatibility claim

The intended release contract is narrow and testable:

Arcane OS can remove its in-tree DBOPFS copy, point its modules directory at the installed package, and continue using the existing application code without changes.

This site does not mark that claim complete until the actual clean Arcane smoke evidence is linked from the release directory.

One coordinated release

Final publication

When every gate is complete, the maintainer will update this page in the same release commit to:

  • replace “release candidate” with the final 1.0.0 status;
  • replace the temporary npm name everywhere;
  • link the immutable test and coverage evidence;
  • link the npm package, Git tag, and GitHub release;
  • state the browsers actually exercised, without extrapolating beyond the evidence;
  • confirm the live GitHub Pages playground and Arcane pointer-only integration.
